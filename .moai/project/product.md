# Product — guess-the-player

> 출처: `.moai/project/interview.md` (Socratic 인터뷰, New Project 경로)

## 프로젝트 개요

- **프로젝트명**: guess-the-player
- **한 줄 설명**: 해외 축구 리그(EPL, 라리가 등) 소속 선수를 힌트로 하나씩 유추해 맞히는 웹 게임. 선수 이름을 한국 미디어에서 통용되는 한글 표기(예: "손흥민", "홀란드")로 보여주는 것이 핵심 차별점이다.
- **도메인**: 스포츠(해외 축구) × 캐주얼 웹 게임
- **플랫폼**: 웹 브라우저 전용 (모바일 네이티브 앱 아님)
- **개발 형태**: 1인 개발(solo)

## 목표(Goal)

해외 축구 리그 선수를 힌트 기반으로 맞히는 웹 게임을 만들되, 선수 이름의 한국어 지원(공식/통용 한글 표기 매핑)을 다른 유사 게임과 구별되는 핵심 가치로 제공한다.

## 타깃 사용자

- 해외 축구(EPL, 라리가 등 유럽 주요 리그)를 즐겨보는 한국어 사용자
- 영어/로마자 표기보다 한글 표기(예: "손흥민", "홀란드")로 선수를 인지하는 국내 축구 팬
- Wordle류 캐주얼 추리 게임을 좋아하지만 "하루 1회 제한"에 아쉬움을 느끼는 사용자

## 핵심 기능

1. **힌트 기반 선수 맞추기 게임 루프**
   - 시스템이 선수 풀에서 **무작위(random)로** 정답 선수를 선정하며, 직전 라운드와 동일 인물이 연속 출제되지 않도록 중복 방지 로직을 적용 (MVP 기본값)
   - 규칙 기반/가중치 기반 선정(예: 난이도별 출제 빈도 조정)은 MVP 이후 v2 개선 후보이며, MVP 시점의 미확정 사항이 아니다
   - 소속 클럽, 포지션, 국적 등 속성을 단계적으로 힌트로 공개
   - 사용자가 선수 이름을 입력/선택하여 정답을 시도
   - 정답 여부와 힌트 소진에 따라 게임 종료 조건 결정

2. **선수명 한국어 표시 (핵심 차별점)**
   - 외부 축구 데이터 API에서 가져온 선수 원어 이름을 한국 미디어 통용 한글 표기로 매핑하여 노출
   - 로마자 표기가 아닌, 국내 팬에게 익숙한 한글 이름으로 힌트/정답/결과 화면 전반을 표시

3. **무제한 플레이**
   - Wordle식 "하루 1문제" 제한 없이 언제든 새 라운드를 시작 가능
   - 별도 로그인 없이도 바로 플레이 가능

## 사용 사례 (Use Cases)

- 사용자가 사이트에 접속해 별도 가입 절차 없이 즉시 게임을 시작한다.
- 사용자는 공개되는 힌트(클럽 → 포지션 → 국적 등)를 순서대로 확인하며 정답 선수를 추리한다.
- 사용자가 정답을 맞히거나 힌트를 모두 소진하면 결과(정답 공개, 한글 표기 포함)를 확인한다.
- 사용자가 결과 확인 후 새로고침 없이 다음 라운드를 바로 다시 시작한다.

## MVP 범위 (Scope)

### In Scope (v1 / MVP)

- 힌트 기반 선수 맞추기 게임 로직 (핵심 루프)
- 외부 축구 데이터 API 연동 (선수 기본 정보: 이름, 소속 클럽, 포지션, 국적, 사진 등)
- 선수명 한국어 매핑 테이블 및 표시 로직
- 무제한 플레이 (일일 제한 없음, 반복 플레이 가능)

### Out of Scope (v1)

- 회원가입 / 로그인 / 계정 시스템
- 개인 플레이 기록 저장
- 리더보드 (순위표)
- 친구 대결 / 소셜 기능
- 축구 외 다른 스포츠 종목 지원
